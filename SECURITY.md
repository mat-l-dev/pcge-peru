## Reportar una vulnerabilidad

No publiques vulnerabilidades de seguridad mediante Issues públicos.

Cuando el reporte privado de vulnerabilidades de GitHub esté habilitado en este repositorio, utiliza esa función para comunicar el problema de forma privada.

Incluye, si es posible:

- Una descripción de la vulnerabilidad.
- Pasos para reproducirla.
- Impacto potencial.
- Versión afectada.
- Cualquier información adicional relevante.
