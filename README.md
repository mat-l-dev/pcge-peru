# PCGE Perú

Librería open source en Python para trabajar con el **Plan Contable General Empresarial (PCGE) del Perú**.

El proyecto tiene como objetivo proporcionar una representación estructurada y programáticamente accesible del PCGE, junto con herramientas para consultar, validar y reutilizar información contable desde Python.

## Estado del proyecto

- Proyecto en desarrollo.

El proyecto se está construyendo inicialmente tomando como referencia la **actualización del PCGE publicada en 2026**, con la intención de mantener los datos contables versionados y permitir futuras actualizaciones sin cambiar la identidad de la librería.

## Objetivos iniciales

* Estructurar el PCGE en un formato reutilizable.
* Consultar cuentas mediante código o denominación.
* Representar la jerarquía entre cuentas, subcuentas y divisionarias.
* Validar la consistencia del catálogo mediante pruebas automatizadas.
* Facilitar su integración en proyectos educativos, contables y de software.

## Compatibilidad

Inicialmente, el proyecto tendrá soporte para **Python 3.14.x**.
